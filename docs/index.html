Method

Target
ERCOT DAM settlement point price, HB_HUBAVG, HE1–24 (CPT). Scored on ATC, peak (HE15–20) and hourly MAE.
Primary model
Huber-ridge regression (IRLS, k = 1.345, λ = 1), fitted separately for four blocks (HE1–6, 7–14, 15–20, 21–24). 120-day window, 30-day recency half-life.
Features
DA[D−1,h], mean DA[D−1], DA[D−7,h]; load-weighted degree-hours |T − 65°F| over 8 load centres; wind CF (5 regions, 100 m speed through a power curve, calibrated to ERCOT actuals) and solar CF (4 regions); day-on-day change in each weather driver; weekend flags. Live inputs clamped to the training range per block.
No look-ahead
Training rows use only DAM through D−1 and the ~24 h-ahead NWP that was available at the time (Open-Meteo previous-runs archive), never realised weather.
Intervals
P10/P90 from rolling 28-day out-of-sample residuals, per block.
Fundamental stack
Diagnostic, not the call. ERCOT installed MW by fuel; gas units at heat rate × (Henry Hub + basis) + VOM; batteries; ORDC-style scarcity adder; load model fitted on EIA-930. Marginal-cost stack, not an offer stack.
Benchmarks
D−1 same hour (persistence) and D−7 same hour. All models scored on identical hours.
Scoring rules
A call counts only if committed before 10:00 CT on D−1 with DAM for D−1 already published. Actuals from ERCOT MIS (NP4-190-CD daily, NP4-180-ER annual), cross-checked against the ERCOT dashboard. Bad days stay in the record.
Schedule
GitHub Actions, ~11 runs/day. Any run after DAM for D−1 publishes (~13:30 CT on D−2) commits the call for D if it is missing.

Known limitations

  1. 3 Nov 2026: evening wind CF fell from ~0.7 to ~0.03. The model lifted HE18–23 to $54–63; DAM cleared $110–161. The model is linear in its drivers, so it cannot reproduce the convex price response when net load meets a supply stack thinned by autumn maintenance outages. Next step: net-load regression with ERCOT resource outage capacity.
  2. Under-reaction: in the walk-forward backtest the realised day-on-day ATC change is ~1.5× the predicted change. Moves are called in the right direction but too small.
  3. The stack is marginal-cost, not offer-based, and sits flat near $25–30 in shoulder months. Next step: fit offer adders by technology from ERCOT 60-day DAM/SCED disclosures.
  4. Gas is Henry Hub spot (EIA, released weekly), not next-day Houston Ship Channel / Waha.
  5. D−1 is a weak benchmark. A net-load regression benchmark is being added.
