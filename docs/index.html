ERCOT day-ahead price forecast

Every morning at about 06:00 Central, before ERCOT's day-ahead market closes at 10:00, this model publishes tomorrow's hourly Hub Average price. Each call is committed to git with a timestamp, then scored against the official cleared price. No data is typed in by hand, and each call links to the GitHub run that made it.

Market observation: day-ahead vs real-time

For each scored day: the day-ahead daily average minus the real-time daily average. A positive number means buyers paid a premium to lock in their price a day early.

How it works

  • Primary model (hybrid). It starts from today's cleared day-ahead price for each hour, then adjusts for the forecast change in temperature, wind and solar between today and tomorrow. It is a robust regression, fitted on the last 120 days and refitted daily, so price spikes can't dominate it.
  • Fundamental stack. Load, wind and solar are modelled from raw weather data, then cleared against a merit-order supply stack (gas heat rates × Henry Hub, batteries, and ERCOT's scarcity adder). It explains the price; the hybrid predicts it.
  • Benchmarks. Persistence is today's day-ahead price for the same hour. Seasonal is the same hour, same weekday last week.
  • Range. The 80% range comes from the model's own out-of-sample errors over the last 28 days.

Integrity rules

  • A call stamped after 10:00 CT the day before is never scored as live.
  • Once a live call is saved, later runs cannot overwrite it. The only exception: before the close, a fallback call can be upgraded to the main model.
  • Actuals are ERCOT's official settlement files, cross-checked against the public dashboard. A day with only a dashboard actual is held back as provisional.
  • A data feed that fails is logged on every call; nothing is filled in by guesswork.
Public data only: ERCOT (MIS and dashboards), Open-Meteo, EIA. A forecasting exercise, not investment advice.
